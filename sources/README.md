# Sources

This directory contains public provenance and attribution records for source material used by Book of Mormon Open Data.

Each source record should document:

- source identifier
- title/name
- author or creator when applicable
- permanent URL or identifier
- license
- retrieval/version information
- which data fields it contributes
- transformations performed by this project

## Initial sources

### Book of Mormon scripture text

Used as primary evidence for identities, relationships, actions, chronology, and other claims. The exact edition/source provenance must be finalized before the first stable release.

### Book of Mormon With Voices Identified

John Hilton III and Shon D. Hopkin, *Book of Mormon With Voices Identified* (2012), BYU ScholarsArchive / WordCruncher.

Source: https://scholarsarchive.byu.edu/wordcruncher/1/

License: Creative Commons Attribution 4.0 International (CC BY 4.0).

Used for speaker attribution and segmentation. Project transformations may include parsing, normalization, canonical identity crosswalking, and aggregation.

### Wikidata

Structured Wikidata statements may be used as candidate facts, identity metadata, and external corroboration.

License: CC0 1.0.

Wikidata descriptions are not used as biographies. References contained in Wikidata statements are provenance clues only; they do not license copying wording from the referenced works.
